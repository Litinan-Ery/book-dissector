# 图书拆解器 v0.2.1 测试用例

- 需求基线：`需求文档.md` v0.2.1，2026-08-09
- 工单基线：`docs/DEVELOPMENT_TICKETS_V0.2.1.md`
- 测试范围：M8 新增能力 + AC-1 至 AC-12 回归
- 当前状态：已执行并通过（2026-08-09）；自动化、UI、Finder 和重启证据见 `docs/TEST_REPORT_V0.2.1.md`

## 1. 测试策略

| 层级 | 目标 | 执行方式 |
| --- | --- | --- |
| 单元测试 | SQLite 事务、删除状态机、精确文件枚举、路径校验 | pytest，临时目录和临时数据库 |
| API 测试 | 状态码、幂等、阻塞条件、数据保留边界 | FastAPI TestClient |
| 并发/故障注入 | claim/delete 竞争、运行中删除、文件/数据库失败、重启恢复 | Event、ThreadPoolExecutor、monkeypatch |
| 前端结构测试 | 状态—按钮矩阵、确认弹窗、错误处理、轮询 | pytest 读取静态资源 + `node --check` |
| 本地端到端 | ego lite 操作本地 Web UI，验证列表变化与确认流程 | ego lite + 当前 checkout 服务 |
| macOS 可见性 | Finder 打开并选中真实导出文件 | 本机人工观察；API 层同时用 subprocess spy 自动化 |

测试默认不得调用真实 DeepSeek、不得读写用户真实 `storage/`、不得调用真实 MyDatabase。除专门的本地可见性用例外，系统命令和 Hook 均使用 spy。

## 2. 测试夹具

### F-01 临时存储

- `BOOKS_DIR=<tmp>/storage/books`
- `INTERMEDIATE_DIR=<tmp>/storage/intermediate`
- `OUTPUT_DIR=<tmp>/storage/output`
- `TASK_DB=<tmp>/storage/tasks.db`
- `RECYCLE_DIR=<tmp>/storage/recycle`
- 每个用例结束调用 `tasks.reset_runtime_for_tests()`。

### F-02 书籍与文件

- `book-a`：有上传副本、提取文本、元数据、删减稿、蒸馏稿、导出 MD。
- `book-b`：用于验证相似 ID/其他书籍不被误删。
- `book1` 与 `book10`：用于验证前缀隔离。
- 外部来源文件：放在临时 `downloads/`，复制一份进入 `BOOKS_DIR`；删除书籍后外部文件必须存在且内容不变。
- 自定义导出文件：路径包含中文、空格和 `;`，位于默认 `OUTPUT_DIR` 之外。

### F-03 任务状态

为同一夹具分别创建 pending、running、cancelled、error、done 任务。done 任务的 `result.output_path` 指向真实 MD；每个任务至少包含一个 `task_unit`，并写入可复用 `unit_cache`。

### F-04 外部调用 spy

- DeepSeek spy：可阻塞当前请求，并记录每次调用开始/结束时间。
- Finder spy：记录 subprocess 的参数、`shell`、超时和调用次数。
- MyDatabase Hook spy：记录调用次数；删除与打开文件夹路径必须始终为 0。
- 故障注入：在第 N 次文件移动、SQLite finalize、Finder 启动处抛出可识别异常。

## 3. 任务删除测试

### TC-TD-01 删除等待中任务

- **级别**：P0；自动化 API/集成
- **覆盖**：FR-9.1、FR-9.3～FR-9.6，AC-13
- **前置**：任务 A、B 均为 pending，A 排在 B 前；A 对应书籍、导出和缓存均存在。
- **步骤**：调用 `DELETE /api/tasks/A`；读取任务列表、任务详情、书库、缓存和输出目录；触发一次调度。
- **预期**：返回 200 且 `state=deleted`；A 立即从列表消失、详情不再可读且永不被 claim；B 仍存在并可运行；A 的 task units 删除，但缓存、书籍、导出和 MyDatabase spy 不变。

### TC-TD-02 删除终态任务

- **级别**：P0；自动化参数化
- **覆盖**：FR-9.1、FR-9.4～FR-9.6，AC-13
- **前置**：分别准备 cancelled、error、done 任务及其 task units；done 任务有导出文件。
- **步骤**：逐一调用 DELETE；刷新列表并重新实例化 TaskStore。
- **预期**：三个请求均返回 200；重启后记录不恢复；task units 级联删除；对应书籍、导出和 `unit_cache` 保留。

### TC-TD-03 删除运行中任务的安全边界

- **级别**：P0；自动化并发/集成
- **覆盖**：FR-9.3、FR-9.6、NFR-3.6、AC-14
- **前置**：任务 A running，DeepSeek spy 阻塞当前请求；任务 B pending。
- **步骤**：调用 DELETE A；在当前请求仍阻塞时读取 A；释放当前请求；等待 worker 完成清理。
- **预期**：首次返回 202 且 `state=deleting`；A 暂时仍存在并带 `delete_requested=true`，界面语义为“正在停止并删除”；删除后不再创建新的模型请求；释放后 A 消失，B 被调度。

### TC-TD-04 待删除运行任务的重启恢复

- **级别**：P0；自动化恢复
- **覆盖**：FR-9.3、NFR-3.5～NFR-3.6、AC-14、AC-17
- **前置**：数据库中存在 `running + delete_requested=true`，并有已完成检查点。
- **步骤**：重新创建 TaskStore，执行启动恢复和调度。
- **预期**：任务被完成删除而不是恢复为 pending/cancelled；无 DeepSeek 请求；检查点删除、共享缓存保留；后续任务可运行。

### TC-TD-05 重复删除幂等

- **级别**：P0；自动化 API
- **覆盖**：FR-9.6、NFR-3.5、AC-17
- **前置**：存在终态任务 A。
- **步骤**：连续两次 DELETE A，再并发发送 10 次 DELETE A。
- **预期**：第一次删除成功，后续均返回定义好的幂等成功并标记 `already_absent=true`；不出现 500、数据库锁或重复副作用。

### TC-TD-06 删除与 worker claim 竞争

- **级别**：P0；自动化并发
- **覆盖**：FR-9.3、NFR-3.5～NFR-3.6、AC-17
- **前置**：A pending；使用同步栅栏让 claim 与 DELETE 同时开始。
- **步骤**：重复执行竞争场景至少 50 次。
- **预期**：每次只允许两种一致结果：删除先完成且 A 从未运行，或 claim 先完成且 A 进入延迟删除；不存在已删除任务继续产生多轮请求、幽灵 running 或 worker 卡死。

### TC-TD-07 删除完成任务不删除交付物

- **级别**：P0；自动化集成
- **覆盖**：FR-9.4、NFR-3.7、AC-13
- **前置**：done 任务 A 已输出 MD，且 MyDatabase Hook 已有一次历史成功记录。
- **步骤**：记录 MD 哈希、外部 MyDatabase 夹具状态和 Hook 次数；DELETE A。
- **预期**：任务删除；MD 仍存在且哈希不变；MyDatabase 夹具不变；Hook 没有新增调用。

### TC-TD-08 删除任务保留可复用缓存

- **级别**：P0；自动化集成
- **覆盖**：FR-9.5、AC-13
- **前置**：任务 A 有合格单元缓存。
- **步骤**：删除 A；为同一书籍、配置和单元创建新任务并运行 fake pipeline。
- **预期**：缓存仍可读取，新任务命中缓存且不调用 DeepSeek spy。

### TC-TD-09 删除与普通取消/恢复隔离

- **级别**：P1；自动化回归
- **覆盖**：FR-8.3～FR-8.5、FR-9.3
- **前置**：任务 A 走普通取消，任务 B 走删除。
- **步骤**：分别执行 cancel、resume 和 DELETE。
- **预期**：A 可恢复；B 不可恢复且最终消失；两者的持久化标记不混淆。

### TC-TD-10 任务删除确认弹窗

- **级别**：P0；前端结构 + ego lite
- **覆盖**：FR-9.2、AC-13
- **前置**：任务列表有五种状态，前端可获得书名。
- **步骤**：逐个点击“删除任务”；先取消一次，再确认一次。
- **预期**：弹窗展示书名、task ID、当前状态和删除边界；确认按钮文字为“删除任务”；取消不发 DELETE；确认只发一次；运行中任务显示延迟删除说明。

### TC-TD-11 非法 task ID 不参与路径或 SQL 拼接

- **级别**：P1；自动化安全
- **覆盖**：NFR-3.5
- **前置**：存在正常任务和文件。
- **步骤**：使用包含 `../`、`*`、引号和超长字符串的 task ID 请求删除。
- **预期**：返回 400 或幂等未找到；正常任务、数据库结构和文件均不变；日志中无未转义 SQL。

## 4. 书库条目删除测试

### TC-BD-01 删除预览内容

- **级别**：P0；自动化 API
- **覆盖**：FR-9.7
- **前置**：book-a 有 1 个 pending、1 个 done 和 1 个 error 任务。
- **步骤**：请求 `GET /api/books/book-a/deletion-preview`。
- **预期**：返回正确书名、book ID、关联任务总数、活跃任务 ID；清理清单包含应用副本/文本/元数据/中间产物/缓存/终态任务，保留清单包含来源文件/导出/MyDatabase。

### TC-BD-02 删除书籍并验证完整边界

- **级别**：P0；自动化集成
- **覆盖**：FR-9.9～FR-9.12、NFR-3.7、AC-16
- **前置**：book-a 无活跃任务，有终态任务、缓存和完整受管文件；外部来源、导出、MyDatabase 夹具存在。
- **步骤**：记录所有文件哈希和 DB 行；DELETE book-a；刷新书库/任务并重启服务。
- **预期**：书库和关联终态任务不再出现；受管文件离开活动目录并进入内部恢复区；book-a 缓存删除；外部来源、导出和 MyDatabase 哈希不变；Hook 调用次数不变。

### TC-BD-03 pending 任务阻塞书籍删除

- **级别**：P0；自动化 API
- **覆盖**：FR-9.8、AC-15
- **前置**：book-a 有 pending 任务 A。
- **步骤**：DELETE book-a。
- **预期**：返回 409，错误包含 A；书籍、任务和文件完全不变；A 仍可被正常调度。

### TC-BD-04 running/正在删除任务阻塞书籍删除

- **级别**：P0；自动化参数化
- **覆盖**：FR-9.8、AC-15
- **前置**：book-a 分别有 running 或 `delete_requested=true` 且尚未清理的任务。
- **步骤**：DELETE book-a。
- **预期**：均返回 409；等待任务删除完成后再次删除书籍才成功。

### TC-BD-05 异步提取中阻塞书籍删除

- **级别**：P0；自动化并发
- **覆盖**：NFR-3.5
- **前置**：book-a 的提取线程被 Event 阻塞，状态 processing。
- **步骤**：DELETE book-a；释放提取线程。
- **预期**：删除返回 409；提取完成后书籍状态一致，不出现删除后重新生成的幽灵条目；随后可正常删除。

### TC-BD-06 先删除活跃任务再删除书籍

- **级别**：P0；自动化端到端
- **覆盖**：FR-9.8、AC-15
- **前置**：book-a 有 running 任务和多个终态任务。
- **步骤**：删除 running 任务并等待其消失；再次 DELETE book-a。
- **预期**：第一次书籍删除被阻塞；活跃任务消失后书籍删除成功；终态任务随书籍清理。

### TC-BD-07 重复删除书籍幂等

- **级别**：P0；自动化 API
- **覆盖**：FR-9.12～FR-9.13、NFR-3.5、AC-17
- **前置**：book-a 可删除。
- **步骤**：连续和并发重复 DELETE book-a。
- **预期**：第一次成功，后续返回幂等成功；恢复区不产生重复冲突，其他书籍和输出不受影响，无 500。

### TC-BD-08 文件移动失败回滚

- **级别**：P0；自动化故障注入
- **覆盖**：FR-9.13、NFR-3.5、AC-17
- **前置**：book-a 有多个受管文件；在移动第 2 个文件时注入 OSError。
- **步骤**：DELETE book-a；读取活动目录、恢复区、删除日志和 TaskStore；重试删除。
- **预期**：首次返回可理解错误；已移动文件被恢复，书籍和任务仍完整可用，准备标记可重试；解除故障后重试成功。

### TC-BD-09 数据库提交失败恢复文件

- **级别**：P0；自动化故障注入
- **覆盖**：FR-9.13、NFR-3.5、AC-17
- **前置**：文件已可成功进入恢复区；在最终 SQLite 事务处注入异常。
- **步骤**：DELETE book-a；检查文件与数据库；解除故障后重试。
- **预期**：数据库事务回滚，文件恢复到活动目录；任务、缓存、书籍三者一致；重试可成功。

### TC-BD-10 清理中崩溃后的启动恢复

- **级别**：P0；自动化恢复
- **覆盖**：FR-9.13、NFR-3.5、AC-17
- **前置**：分别构造“已写清单未移动”“已移动未提交 DB”“DB 已提交未标记完成”三种持久状态。
- **步骤**：模拟服务启动，执行删除恢复。
- **预期**：每种状态按日志确定性回滚或完成；最终不存在半套文件、孤儿任务、幽灵书籍；重复启动无额外副作用。

### TC-BD-11 删除与新建任务竞争

- **覆盖**：FR-9.8、FR-9.13、NFR-3.5

### TC-BD-12 相似 book ID 与路径隔离

## 5. 完成任务打开文件夹测试

### TC-OF-01 状态—按钮矩阵

- **级别**：P0；自动化 API + ego lite
