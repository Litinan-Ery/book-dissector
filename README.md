# 图书拆解器

## 项目目标

帮助用户节约阅读时间，提高知识获取效率。

当前产品范围以第一版的简洁体验为主体：快速删减、压缩、提取精华并导出 Markdown。只保留少量不会增加阅读负担的可靠性改进。

## 核心功能

将导入的书籍进行多级精简，最终产出精华版 Markdown 文件：

1. **删除无关内容**：剔除与主旨无关的部分，如版权页、目录、尾注、参考文献等。
2. **压缩核心部分**：按书籍类型和压缩强度，对核心章节进行大幅压缩。
3. **提取精华**：保留核心观点，以及其中最关键、最生动的例子。
4. **识别特殊内容**：识别表格、图片、公式和代码块；当前不能处理时明确告警。
5. **可靠完成任务**：任务进入持久化队列，支持检查点、取消、恢复、缓存和失败单元重试。
6. **导出成果**：将提取出的精华部分导出为 MD（Markdown）文件。
7. **本地管理**：可独立删除任务或书库条目；已完成任务可在 Finder 中定位实际导出文件。

不再要求自适应预算、全书定向扫描、强制结构化知识单元、强制原文锚点、全书语义去重、可逆删减映射或复杂质量门禁。

## 使用流程

```text
导入书籍
  → 开始前查看 token / API 调用量 / 时间 / 成本估算
  → 首次云端调用确认必要正文片段会发送给 DeepSeek
  → 一键开始拆解
  → 页面持续显示删减、压缩、提取和导出阶段
  → 导出 MD 文件
```

默认只需点击一次“开始拆解”。任务运行期间可以取消；关闭页面或服务重启后，可以从检查点恢复，失败时只重试失败单元。任务队列中的所有状态均可删除；运行中任务会先停止新模型请求，再在安全边界完成删除。

## 删除与保留边界

- **删除任务**：删除任务记录、检查点和失败信息；保留书籍、已导出 Markdown、MyDatabase 内容和可复用缓存。
- **删除书籍**：清理应用内导入副本、提取/中间文件、书籍缓存和关联终态任务；保留导入来源原文件、既有导出和 MyDatabase 内容。受管文件先移入 `storage/recycle/books/`，失败或重启可回滚。
- **打开文件夹**：仅已完成任务展示；使用任务持久化的真实 `output_path`，以 `open -R` 只读定位，不重新导出或触发 Hook。

## 技术方案（已确认）

- **界面形态**：本地 Web 服务；原文件、任务状态、检查点和缓存保存在本机。
- **提炼引擎**：DeepSeek V4 Flash 大模型 API。必要正文片段会发送给 DeepSeek，首次调用前必须明确提示并取得用户确认。
- **API Key**：由用户自行填写，仅存本机 `config.json`，权限 0600。
- **压缩目标**：保留原篇幅约 15%，按书籍类型差异化（社科/商业约 15%；小说保留主线剧情与关键场景，低于 15%；技术书略高于 15%）。
- **多模态边界**：识别表格、图片、公式和代码块；不能可靠处理时告警，本版不要求自动理解或重建。
- **不做**：笔记、批注、书签及复杂知识学习系统。

详细要求见 [需求文档.md](需求文档.md)。

## 项目结构

```text
图书拆解器/
├── README.md            # 本文件
├── 需求文档.md           # 详细需求（FR/NFR/验收标准/里程碑）
├── requirements.txt     # Python 依赖
├── config.json          # 本地配置（API Key，不入库，权限 0600）
├── app/
│   ├── main.py          # FastAPI 入口（uvicorn app.main:app）
│   ├── config.py        # 路径、服务参数与密钥存储
│   ├── api/             # 导入、设置、任务和导出 API
│   ├── core/            # 格式提取、删减、压缩、流水线、缓存与任务持久化
│   ├── models/          # Pydantic 数据模型
│   └── static/          # 前端页面
├── storage/             # 工作数据（不入库）
│   ├── books/           # 导入的原书
│   ├── intermediate/    # 中间产物
│   ├── output/          # 导出的精华 MD
│   ├── recycle/books/   # 书籍可恢复删除区
│   └── tasks.db         # 持久化队列、任务、检查点与缓存
└── tests/               # 自动化测试
```

## 快速启动

```bash
cd 图书拆解器
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
```

浏览器打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)。

运行自动化测试：

```bash
.venv/bin/python -m pytest -q
```
