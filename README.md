# 图书拆解器

## 项目目标

帮助用户用尽可能少的阅读与等待时间，获得尽可能多的、可追溯的核心知识。

项目不再把“压缩到固定篇幅”视为唯一目标，而是同时优化：

- **知识完整性**：核心知识不因章节切分、格式解析或压缩而静默丢失。
- **知识唯一性**：跨章节重复观点只保留一次，并保留全部来源位置。
- **知识忠实性**：重要观点、数据和例子均能回到原文核验，不把模型推断伪装成作者原意。
- **时间效率**：减少不必要的模型调用、重复处理和人工操作，并支持中断后继续。

## 核心功能

将导入的书籍进行结构校验、价值评估和分层压缩，最终产出可追溯的精华版 Markdown 文件：

1. **校验输入结构**：检查章节顺序、偏移、覆盖率、重复区间和不可解析内容，质量不达标时不进入压缩阶段。
2. **删除无关内容**：剔除版权页、目录、广告等无关内容，保留可恢复记录。
3. **动态分配预算**：先评估章节的相关性、新颖度、依赖性和证据价值，再分配压缩篇幅；不再逐章等比例压缩。
4. **提取并核验精华**：保留核心观点、逻辑、证据和关键例子，为每个重要结论建立原文锚点，并执行全书去重。
5. **高效完成任务**：支持进度持久化、取消、断点续跑、失败单元重试和中间结果复用。
6. **导出成果**：将精华内容、来源锚点、质量报告和过程统计导出为 MD（Markdown）文件。

## 使用流程

```
导入书籍
  → 结构与覆盖校验（P0）
  → 删减无关内容
  → 全书定向扫描与动态预算（P1）
  → 分段提炼
  → 全书去重与原文锚点校验（P0）
  → 导出 MD 与质量报告
```

默认由一个端到端任务完成以上流程；高级用户可以查看或干预各阶段，但系统不得静默跳过质量门禁。

## 改进优先级

### P0：先保证知识不丢、不重、不编

- 修复并验证 EPUB/PDF/TXT/MD 的章节结构、正文覆盖和删减后偏移。
- 对核心观点、数据和例子建立可程序校验的原文锚点。
- 在全书范围合并重复观点，同时保留重复观点的全部出处。
- 对表格、公式、图片、代码布局等当前无法可靠理解的内容明确告警，不得静默丢弃。
- 建立格式夹具、金标样本和端到端自动化测试；P0 未通过时不得发布 P1/P2 优化。

### P1：改变压缩预算分配

- 保留全书总压缩目标和“保守 / 标准 / 激进”档位，但不再给每章相同比例。
- 先执行全书定向扫描，再按相关性、新颖度、前置依赖和证据价值分配章节预算。
- 低价值或重复章节获得更少预算；关键机制、核心证据和必要前置知识获得更多预算。
- 章节提炼完成后执行全书级术语统一、逻辑合并和重复消除。

### P2：降低等待时间和操作成本

- 将删减、预算分配、提炼、校验和导出整合为一个可观察的端到端任务。
- 复用网络连接，采用有上限的并发、重试退避和内容缓存。
- 支持取消、断点续跑、服务重启恢复和仅重试失败单元。
- 开始前展示预计处理时间、API 调用量和成本区间；完成后记录真实数据。
- 所有加速方案必须重新通过 P0 质量门禁，不得以丢失知识换取速度。

## 技术方案（已确认）

- **界面形态**：本地 Web 服务；原文件和中间产物保存在本机。
- **提炼引擎**：DeepSeek V4 Flash 大模型 API。启用云端提炼时，必要的正文片段会发送给 DeepSeek；界面必须在首次调用前明确提示。API Key 由用户自行填写，仅存本机 `config.json`，权限 0600。
- **压缩目标**：标准模式以全书核心内容约 15% 为总预算，按书籍类型和章节信息价值动态分配，不要求各章等比例。
- **质量前置**：章节结构、正文覆盖、原文锚点和全书去重是硬性门禁；门禁失败时不得把结果标记为完成。
- **不做**：笔记/批注/书签功能

详见 `需求文档.md`。

- **P1 代码已实现**：全书定向扫描、四因子评分、按全书总量分配预算、预算偏差报告与全书级合并。

- **自动化基线**：94 个测试通过，覆盖格式提取、章节偏移、删减映射、模态清单、锚点、去重、预算、缓存、取消、持久化、API、10 本书队列、并发入队、失败隔离、流水线和静态前端。

## 项目结构

```
图书拆解器/
├── README.md            # 本文件
├── 需求文档.md           # 详细需求（FR/NFR/验收标准/里程碑）
├── requirements.txt     # Python 依赖
├── config.json          # 本地配置（API Key，不入库，权限 0600）
├── app/
│   ├── main.py          # FastAPI 入口（uvicorn app.main:app）
│   ├── config.py        # 路径 / 服务参数 / 密钥存储
│   ├── api/             # API 路由：books（导入）、settings（密钥）、tasks（拆解）
│   ├── core/            # 提取、映射、锚点、质量、预算、流水线、缓存与任务持久化
│   ├── models/          # Pydantic 数据模型
│   └── static/          # 前端页面（index.html / app.js / style.css）
├── storage/             # 工作数据（不入库）
│   ├── books/           # 导入的原书
│   ├── intermediate/    # 中间产物（删减稿、压缩稿）
│   ├── output/          # 导出的精华 MD
│   ├── runs/            # 每次运行独立的版本化审计产物
│   └── tasks.db         # SQLite 任务、检查点、队列与单元缓存
└── tests/               # P0 格式夹具、金标样本、质量门禁与端到端测试
```

## 快速启动

```bash
cd 图书拆解器
python3.12 -m venv .venv          # 首次
.venv/bin/pip install -r requirements.txt   # 首次
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
```

浏览器打开 http://127.0.0.1:8000

运行自动化回归：

```bash
.venv/bin/python -m pytest -q
```
